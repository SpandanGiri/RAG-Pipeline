# Getting Started

Welcome to the Acme Cloud platform. This guide covers installation and initial setup.

## Installation

Install the CLI using pip:

    pip install acme-cli

### System Requirements
You need Python 3.10 or higher and at least 512MB of free disk space.

## Quickstart

Run `acme init` to generate your configuration file. Once initialized, you can deploy your first service with `acme deploy`.
