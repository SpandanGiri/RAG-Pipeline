# Rate Limits

API requests are rate-limited per workspace to ensure fair usage.

## Tier Quotas

- **Free:** 60 requests per minute
- **Pro:** 600 requests per minute
- **Enterprise:** Custom limits

## Handling 429 Errors

When you exceed your quota, the API returns HTTP 429 Too Many Requests along with a Retry-After header. Implement exponential backoff with jitter in your HTTP client to avoid thundering herd retries.
